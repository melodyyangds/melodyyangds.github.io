The story

Problem
Monthly reports meant exporting 4 sheets and combining them by hand. It took 2 to 5 days, and the numbers didn't always match.
What I did
First I got all 4 teams on the same request form, so the data lined up. Then I set up an automatic refresh into one data model and built the dashboard on top of it.
What changed
Reports went from days to under an hour. Ad hoc requests dropped about 40%, because people could just check the dashboard instead of asking me.

Query behind the monthly view · BigQuery-style SQL over the star schema 
-- One row per month x function: feeds the trend line, tiles, and table view
SELECT
  DATE_TRUNC(r.submitted_date, MONTH)                         AS month,
  f.function_name,
  COUNT(*)                                                    AS requests,
  SUM(r.quantity)                                             AS units,
  APPROX_QUANTILES(                                           -- approximate median
    DATE_DIFF(r.completed_date, r.submitted_date, DAY), 2
  )[OFFSET(1)]                                                AS median_turnaround_days,
  AVG(IF(r.completed_date <= r.needed_by_date, 1, 0))        AS on_time_rate
FROM fact_request AS r
JOIN dim_function      AS f USING (function_id)
JOIN dim_business_unit AS b USING (business_unit_id)
WHERE r.status = 'Complete'
  AND (@business_unit IS NULL OR b.business_unit_name = @business_unit)
GROUP BY month, f.function_name
ORDER BY month, f.function_name;
